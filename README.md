# Power BI Yoga Analysis Dashboard

Power BI Abschlussprojekt zur Analyse von Gesundheits- und Trainingsdaten mit DAX, Power Query und interaktivem Yoga-Zielrechner.

## Projektübersicht

Interaktives Power-BI-Abschlussprojekt zur Analyse von Gesundheits-, Trainings- und demografischen Daten.

Das Dashboard „Neural Namaste – Yoga Analyse“ untersucht Zusammenhänge zwischen Yoga-Training, Gesundheitskennzahlen und demografischen Merkmalen.

Das Projekt umfasst mehrere interaktive Berichtsseiten und ermöglicht die Analyse der Daten nach Geschlecht, Altersgruppe und Erfahrungsstufe.

## Dashboard-Seiten

### Übersicht
Zentrale Kennzahlen und Analysen zu:
- Anzahl der Personen und Yoga-Teilnehmer
- Yoga-Anteil
- durchschnittlichem BMI
- Trainingsdauer
- Geschlechter- und Altersverteilung
- Trainingsarten und Erfahrungsstufen

### Gesundheit
Analyse verschiedener Gesundheitskennzahlen:
- BMI
- Körperfett
- Gewicht
- Ruhepuls
- Wasseraufnahme
- Zusammenhang zwischen Gewicht und BMI
- Vergleich zwischen Yoga und Nicht-Yoga

### Training
Analyse des Trainingsverhaltens:
- Trainingsdauer
- Kalorienverbrauch
- Wasseraufnahme
- Trainingshäufigkeit
- maximale Herzfrequenz
- Unterschiede nach Alter und Erfahrungsstufe

### Yoga-Zielrechner
Interaktiver Rechner zur Abschätzung eines persönlichen Trainingsziels anhand von:
- Trainingstagen pro Woche
- Minuten pro Trainingseinheit
- Ausgangsgewicht
- Zielgewicht

Der Rechner ermittelt unter anderem die benötigten Trainingseinheiten, den geschätzten Kalorienverbrauch und die voraussichtliche Dauer bis zum Ziel.

## Verwendete Technologien

- Microsoft Power BI
- Power Query
- DAX
- Datenmodellierung
- Datenvisualisierung
- Interaktive Filter und Slicer
- What-if-Parameter / interaktive Berechnungen
